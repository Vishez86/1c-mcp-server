## Приведение типа (ВЫРАЗИТЬ)

Явно преобразует значение к указанному типу. **Необходимо для полей составного типа.**

```
ВЫРАЗИТЬ(<выражение> КАК <тип>)
```

Примеры:
```sql
-- Привести составную ссылку к конкретному типу:
ВЫРАЗИТЬ(Регистратор КАК Документ.РеализацияТоваровУслуг)

-- Привести число к нужной точности:
ВЫРАЗИТЬ(Сумма КАК ЧИСЛО(15, 2))

-- К строке:
ВЫРАЗИТЬ(Код КАК СТРОКА(10))

-- К булеву:
ВЫРАЗИТЬ(Значение КАК БУЛЕВО)

-- К дате:
ВЫРАЗИТЬ(Значение КАК ДАТА)
```

Примитивные типы для приведения: `ЧИСЛО(<длина>, <точность>)`, `СТРОКА(<длина>)`, `БУЛЕВО`, `ДАТА`. Можно приводить и к ссылочному типу (имя таблицы).

> Если значение содержит в составном типе требуемый тип — приведение даёт это значение; для значений других типов результат `NULL`. Если требуемого типа в составе нет вовсе — запрос завершится ошибкой.

## Агрегатные функции

Используются с `СГРУППИРОВАТЬ ПО`, `ИМЕЮЩИЕ`, `ИТОГИ`, `УПОРЯДОЧИТЬ ПО`.

| Функция | Описание | Пример |
|---------|----------|--------|
| `СУММА(<поле>)` | Сумма | `СУММА(Количество)` |
| `СРЕДНЕЕ(<поле>)` | Среднее | `СРЕДНЕЕ(Цена)` |
| `МИНИМУМ(<поле>)` | Минимум | `МИНИМУМ(Дата)` |
| `МАКСИМУМ(<поле>)` | Максимум | `МАКСИМУМ(Дата)` |
| `КОЛИЧЕСТВО(*)` | Число всех строк | `КОЛИЧЕСТВО(*)` |
| `КОЛИЧЕСТВО(<поле>)` | Число значений, не равных NULL | `КОЛИЧЕСТВО(Контрагент)` |
| `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ <поле>)` | Число различных значений | `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Контрагент)` |

**Правила:**
- `СУММА` и `СРЕДНЕЕ` применимы только к числовым полям (или составным с числом; нечисловое значение в выборке, кроме NULL, даёт ошибку).
- `МАКСИМУМ`/`МИНИМУМ` — к значениям любого типа; `МАКСИМУМ` не применяется к `ХранилищеЗначения`, `МоментВремени` и строкам неограниченной длины.
- Не использовать поле группировки внутри агрегатной функции (кроме полей вложенной таблицы).
- В списке `ВЫБРАТЬ` агрегатные функции — **только для получения результата**, не для проверки условий. Конструкции вида `КОГДА КОЛИЧЕСТВО(*) > 1 ТОГДА …` в `ВЫБРАТЬ` на разных СУБД ведут себя по-разному; для условий используй `ИМЕЮЩИЕ`.

## Функции даты и времени

### Извлечение компонента

| Функция | Возвращает | Пример |
|---------|-----------|--------|
| `ГОД(<дата>)` | Год | `ГОД(Дата)` → 2024 |
| `КВАРТАЛ(<дата>)` | Квартал (1–4) | `КВАРТАЛ(Дата)` → 1 |
| `МЕСЯЦ(<дата>)` | Месяц (1–12) | `МЕСЯЦ(Дата)` → 3 |
| `ДЕНЬГОДА(<дата>)` | День года (1–366) | `ДЕНЬГОДА(Дата)` |
| `ДЕНЬ(<дата>)` | День месяца (1–31) | `ДЕНЬ(Дата)` → 15 |
| `ДЕНЬНЕДЕЛИ(<дата>)` | День недели (1=Пн..7=Вс) | `ДЕНЬНЕДЕЛИ(Дата)` |
| `НЕДЕЛЯ(<дата>)` | Номер недели года | `НЕДЕЛЯ(Дата)` |
| `ЧАС(<дата>)` | Час (0–23) | `ЧАС(Дата)` |
| `МИНУТА(<дата>)` | Минута (0–59) | `МИНУТА(Дата)` |
| `СЕКУНДА(<дата>)` | Секунда (0–59) | `СЕКУНДА(Дата)` |

> Если аргумент `NULL` — результат `NULL`. Прочие нечисловые значения недопустимы.
> Для `НЕДЕЛЯ`/`ДЕНЬНЕДЕЛИ` учитывается «Первый день недели» из региональных установок ИБ.

### Границы периода

| Функция | Описание |
|---------|----------|
| `НАЧАЛОПЕРИОДА(<дата>, <период>)` | Начало периода. `<период>`: МИНУТА, ЧАС, ДЕНЬ, НЕДЕЛЯ, МЕСЯЦ, КВАРТАЛ, ГОД, ДЕКАДА, ПОЛУГОДИЕ |
| `КОНЕЦПЕРИОДА(<дата>, <период>)` | Конец периода (те же значения периода) |

```sql
НАЧАЛОПЕРИОДА(Дата, МЕСЯЦ)    -- первый день месяца, 00:00:00
КОНЕЦПЕРИОДА(Дата, КВАРТАЛ)    -- последний момент квартала, 23:59:59
```

### Арифметика дат

| Функция | Описание |
|---------|----------|
| `ДОБАВИТЬКДАТЕ(<дата>, <период>, <кол-во>)` | Прибавить N периодов к дате |
| `РАЗНОСТЬДАТ(<дата1>, <дата2>, <период>)` | Разница между датами в единицах периода |

```sql
ДОБАВИТЬКДАТЕ(Дата, МЕСЯЦ, 3)         -- +3 месяца
ДОБАВИТЬКДАТЕ(Дата, ДЕНЬ, -7)          -- −7 дней
РАЗНОСТЬДАТ(ДатаНач, ДатаКон, ДЕНЬ)   -- дней между датами
```

**Различие в наборе периодов:**
- `ДОБАВИТЬКДАТЕ` — `СЕКУНДА, МИНУТА, ЧАС, ДЕНЬ, НЕДЕЛЯ, МЕСЯЦ, КВАРТАЛ, ГОД, ДЕКАДА, ПОЛУГОДИЕ` (Декада = строго 10 дней).
- `РАЗНОСТЬДАТ` — только `СЕКУНДА, МИНУТА, ЧАС, ДЕНЬ, МЕСЯЦ, КВАРТАЛ, ГОД` (без Недели/Декады/Полугодия).

> ⚠️ `РАЗНОСТЬДАТ` считает **календарную** разницу — её **нельзя** использовать для расчёта банковских/рабочих дней.
> ⚠️ `РАЗНОСТЬДАТ` **нельзя** использовать при задании значения параметра `Период` виртуальной таблицы.
> Точность секунды/минуты/часа может по-разному учитывать переход на зимнее/летнее время на разных СУБД — для дискретности «дни/месяцы» считай именно в днях/месяцах.

> `ПОДСТРОКА` в основном условии `ГДЕ` отключает индекс. Использовать только в дополнительных условиях.
> Если аргумент `NULL` — результат `NULL`.

## Функции типов

| Функция | Описание | Пример |
|---------|----------|--------|
| `ТИПЗНАЧЕНИЯ(<выр>)` | Тип значения | `ТИПЗНАЧЕНИЯ(Ссылка)` |
| `ТИП(<имя_типа>)` | Объект типа для сравнения | `ТИП(Справочник.Контрагенты)` |
| `ССЫЛКА` | Оператор проверки типа ссылки | `Рег ССЫЛКА Документ.Реализация` |
| `ПРЕДСТАВЛЕНИЕ(<выр>)` | Строковое представление значения | `ПРЕДСТАВЛЕНИЕ(Контрагент)` |
| `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(<ссылка>)` | UUID ссылки (тип УникальныйИдентификатор) | `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(Ссылка)` |

```sql
-- Фильтр по типу значения субконто:
ГДЕ ТИПЗНАЧЕНИЯ(Субконто1) = ТИП(Справочник.Контрагенты)

-- Через параметр:
ГДЕ ТИПЗНАЧЕНИЯ(Регистратор) = &ТипДокумента
```

> В `ТИП(...)` имя типа указывается без кавычек: `ТИП(Строка)`, `ТИП(Справочник.Номенклатура)`.
> Результат `ПРЕДСТАВЛЕНИЕ` нельзя вкладывать в другие функции (кроме самого `ПРЕДСТАВЛЕНИЕ`).

## Математические функции

| Функция | Описание |
|---------|----------|
| `ОКР(<число>, <разрядность>)` | Округление до N знаков (режим Окр15как20 — половина вверх по модулю); разрядность необязательна, по умолчанию 0; отрицательная — округление в целой части |
| `ЦЕЛ(<число>)` | Целая часть (отбрасывает дробную) |

```sql
ОКР(Сумма / Количество, 2)   -- до 2 знаков
ЦЕЛ(Сумма / 100)             -- целая часть
```

**Точность арифметики:** не ниже 8 знаков после запятой. На разных СУБД результат может незначительно отличаться. При делении проверяй делитель на отличие от нуля.

### ⚠ АБС (модуль числа) — функции НЕТ

**`АБС` отсутствует в языке запросов 1С** (подтверждено и скриншотом конфигуратора БП КОРП 3.0.192.25, и официальной документацией ИТС 8.3.37 — в перечне математических функций её нет).
Математические функции платформы: `ОКР`, `ЦЕЛ`, алгебраические (`EXP`, `LOG`, `LOG10`, `POW`, `SQRT`) и тригонометрические — `АБС` среди них нет.

**Замена через `ВЫБОР КОГДА` (работает везде — в ВЫБРАТЬ, ГДЕ, ИМЕЮЩИЕ):**

```sql
-- Модуль числа:
ВЫБОР КОГДА X < 0 ТОГДА -X ИНАЧЕ X КОНЕЦ

-- Пример в ВЫБРАТЬ:
ВЫБОР КОГДА Сумма - СуммаНУ < 0 ТОГДА -(Сумма - СуммаНУ) ИНАЧЕ Сумма - СуммаНУ КОНЕЦ КАК МодульРазницы
```

**Замена в ИМЕЮЩИЕ — два условия (нельзя вложить ВЫБОР КОГДА в агрегат):**

```sql
-- Вместо: ИМЕЮЩИЕ АБС(СУММА(X) - СУММА(Y)) > 50000
ИМЕЮЩИЕ
    СУММА(X) - СУММА(Y) > 50000
    ИЛИ СУММА(X) - СУММА(Y) < -50000
```

**Альтернатива для сложных случаев — временная таблица:**
```sql
-- Шаг 1: посчитать разницу во временной таблице
ВЫБРАТЬ СУММА(X) - СУММА(Y) КАК Разница ... ПОМЕСТИТЬ ВТ_Разницы ...

-- Шаг 2: фильтровать по готовому полю — ВЫБОР КОГДА уже не нужен
ВЫБРАТЬ ... ИЗ ВТ_Разницы ГДЕ
    ВЫБОР КОГДА Разница < 0 ТОГДА -Разница ИНАЧЕ Разница КОНЕЦ > 50000
```

## Арифметические операторы

`+`, `-`, `*`, `/` — стандартная арифметика. Точность — не ниже 8 знаков после запятой.

> Операция `+` не поддерживает строки неограниченной длины (более 1024 символов).
> **В `ГДЕ`:** использовать только в дополнительных условиях (в основном — отключает индекс).
> Тип результата `СУММА()`, `СРЕДНЕЕ()`, `ВЫРАЗИТЬ()`, `*`, `+`, `-` над числами — число произвольной точности и разрядности.

## Константы и литералы

| Тип | Синтаксис | Пример |
|-----|-----------|--------|
| Булево | `ИСТИНА` / `ЛОЖЬ` | `ГДЕ Проведен = ИСТИНА` |
| Число | Десятичный литерал | `1000`, `3.14` |
| Строка | Двойные кавычки | `"Текст"` |
| Строка с кавычкой | Удвоение `"` | `"Компания ""Рога и Копыта"""` |
| Дата | `ДАТАВРЕМЯ(<Г>, <М>, <Д> [, <ч>, <мин>, <с>])` | `ДАТАВРЕМЯ(2024, 1, 15)` |
| NULL | `NULL` | `ЕСТЬNULL(X, 0)` |
| Неопределено | `НЕОПРЕДЕЛЕНО` | |
| Перечисление/предопределённое | `ЗНАЧЕНИЕ(...)` | `ЗНАЧЕНИЕ(Перечисление.ТипыЦен.Оптовая)` |
| Пустая ссылка | `ЗНАЧЕНИЕ(Справочник.X.ПустаяСсылка)` | |
| Тип | `ТИП(<имя типа>)` | `ТИП(Документ.РасходнаяНакладная)` |

> ⚠️ Максимальная дата литерала `ДАТАВРЕМЯ` — `31.12.3999 23:59:59`. Удобно как «бесконечный» верхний край периода.
> `ЗНАЧЕНИЕ(...)` обращается к предопределённым данным (перечисления, предопределённые элементы справочников, планов счетов/видов характеристик/расчёта, пустые ссылки, точки маршрута бизнес-процессов) и к системным перечислениям (`ВидДвиженияНакопления`, `ВидСчета`, `ВидДвиженияБухгалтерии`).
>
> **Параметры:** `&Имя` — внешние значения, передаваемые в запрос. Всегда предпочитать параметры конкатенации строк.
