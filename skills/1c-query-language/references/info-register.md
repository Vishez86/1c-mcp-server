## Основная таблица

`РегистрСведений.<Имя>` — содержит все записи.

### Стандартные поля (зависят от настройки регистра)

| Поле | Когда существует | Описание |
|------|-----------------|----------|
| `<ИмяИзмерения>` | Всегда | Значение измерения |
| `<ИмяРесурса>` | Всегда | Значение ресурса |
| `<ИмяРеквизита>` | Всегда | Значение реквизита |
| `Период` | Только периодические | Дата записи |
| `Регистратор` | Только подчинённые регистратору | Ссылка на документ |
| `НомерСтроки` | Только подчинённые регистратору | Номер строки в наборе |
| `Активность` | Только подчинённые регистратору | Влияние на срез |

### Виды регистров

- **Независимый непериодический** — нет поля `Период`, нет `Регистратор`
- **Независимый периодический** — есть `Период`, нет `Регистратор`
- **Подчинённый регистратору** — есть `Регистратор`, `НомерСтроки`, `Активность`; периодичность — «По позиции регистратора»

## Виртуальные таблицы СрезПоследних / СрезПервых

Только для **периодических** регистров.

```
РегистрСведений.<Имя>.СрезПоследних(<Период>, <Условие>)
РегистрСведений.<Имя>.СрезПервых(<Период>, <Условие>)
```

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Период` | Дата, МоментВремени, Граница | Дата среза. Если не задан — берётся самая последняя/первая запись без ограничений |
| `Условие` | Условие на языке запросов | Фильтр по полям **исходной** таблицы до построения среза |

### Состав полей

Те же поля, что в основной таблице (измерения, ресурсы, реквизиты + `Период`, `Регистратор`, `НомерСтроки`, `Активность` — при наличии).

## Критичное отличие: ГДЕ vs параметр Условие

> ⚠️ **Важно:** фильтр в `ГДЕ` и фильтр в параметре `Условие` дают **разный результат**.

| Способ | Логика выполнения |
|--------|-------------------|
| `ГДЕ Цена >= 300` | Сначала строится срез **всех** записей, потом отбираются с `Цена >= 300` |
| `.СрезПоследних(, Цена >= 300)` | Сначала отбираются исходные записи с `Цена >= 300`, потом из них строится срез |

**Пример разницы:**

Если цена товара менялась: 500 → 200 → 400:
- `ГДЕ Цена >= 300` → вернёт последнюю запись (400) ✓
- `.СрезПоследних(, Цена >= 300)` → отсеет запись 200, построит срез из 500 и 400, вернёт 400 ✓

Но если история: 500 → 200:
- `ГДЕ Цена >= 300` → ничего не вернёт (последняя = 200)
- `.СрезПоследних(, Цена >= 300)` → вернёт 500 (последняя из тех, что >= 300)

**Правило:** используй параметр `Условие` для фильтрации по **измерениям**; `ГДЕ` — для фильтрации по результату среза.

## Примеры

### Все записи непериодического регистра

```sql
ВЫБРАТЬ РАЗЛИЧНЫЕ
    Сотрудники.ФизическоеЛицо,
    Сотрудники.Подразделение,
    Сотрудники.Должность
ИЗ
    РегистрСведений.Сотрудники КАК Сотрудники
ГДЕ
    Сотрудники.Подразделение.Наименование ПОДОБНО "%Отдел%"
УПОРЯДОЧИТЬ ПО
    Сотрудники.ФизическоеЛицо
```

### Срез последних без ограничений

```sql
ВЫБРАТЬ *
ИЗ
    РегистрСведений.УчетнаяПолитикаПредприятия.СрезПоследних()
УПОРЯДОЧИТЬ ПО
    Период
```

### Срез последних на дату

```sql
ВЫБРАТЬ *
ИЗ
    РегистрСведений.Цены.СрезПоследних(&ДатаСреза, )
```

### Срез последних с условием по измерению (рекомендуется)

```sql
ВЫБРАТЬ
    СрезПоследних.Номенклатура,
    СрезПоследних.ТипЦены,
    СрезПоследних.Цена
ИЗ
    РегистрСведений.Цены.СрезПоследних(
        &ДатаСреза,
        Номенклатура = &Товар
    ) КАК СрезПоследних
```

### Подчинённый регистратору — по документу

```sql
ВЫБРАТЬ
    ЦеныНоменклатуры.Период,
    ЦеныНоменклатуры.Номенклатура,
    ЦеныНоменклатуры.ТипЦены,
    ЦеныНоменклатуры.Цена
ИЗ
    РегистрСведений.ЦеныНоменклатуры КАК ЦеныНоменклатуры
ГДЕ
    ЦеныНоменклатуры.Регистратор = &РегистраторОтбора
УПОРЯДОЧИТЬ ПО
    ЦеныНоменклатуры.Период
```

### Поиск неиспользуемых видов характеристик (паттерн LEFT JOIN + IS NULL)

```sql
ВЫБРАТЬ
    ВидыХарактеристик.Наименование
ИЗ
    ПланВидовХарактеристик.ВидыХарактеристик КАК ВидыХарактеристик
    ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.ДополнительныеХарактеристики КАК Характеристики
        ПО ВидыХарактеристик.Ссылка = Характеристики.ВидХарактеристики
ГДЕ
    НЕ ВидыХарактеристик.ЭтоГруппа
    И Характеристики.ЗначениеХарактеристики ЕСТЬ NULL
```
