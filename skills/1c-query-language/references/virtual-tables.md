## ОборотыДтКт

Обороты между корреспондирующими счетами (Дт ↔ Кт).

### Параметры виртуальной таблицы

| Параметр | Описание |
|----------|----------|
| `НачалоПериода` | Начало периода |
| `КонецПериода` | Конец периода |
| `Периодичность` | Периодичность (ДЕНЬ, МЕСЯЦ, КВАРТАЛ, ГОД и др.) |
| `УсловиеСчетаДт` | Условие на счёт дебета |
| `СубконтоДт` | Условие на субконто дебета |
| `УсловиеСчетаКт` | Условие на счёт кредита |
| `СубконтоКт` | Условие на субконто кредита |
| `Условие` | Дополнительное условие |

### Измерения

`СчетДт`, `СчетКт`, `СубконтоДт1`, `СубконтоДт2`, `СубконтоДт3`, `СубконтоКт1`, `СубконтоКт2`, `СубконтоКт3`, `Организация`, `ВалютаДт`, `ВалютаКт`, `ПодразделениеДт`, `ПодразделениеКт`

### Ресурсы

`СуммаОборот`, `ВалютнаяСуммаОборотДт`, `ВалютнаяСуммаОборотКт`, `КоличествоОборотДт`, `КоличествоОборотКт`, `СуммаНУОборотДт`, `СуммаНУОборотКт`, `СуммаПРОборотДт`, `СуммаПРОборотКт`, `СуммаВРОборотДт`, `СуммаВРОборотКт`

> ⚠️ **Нет полей** `КоличествоОборот` и `Количество` — только `КоличествоОборотДт` и `КоличествоОборотКт`.

### Пример

```sql
ВЫБРАТЬ
    Обороты.СчетДт,
    Обороты.СчетКт,
    Обороты.СуммаОборот
ИЗ
    РегистрБухгалтерии.Хозрасчетный.ОборотыДтКт(
        &НачДата,
        &КонДата,
        ,
        СчетДт В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.НДСПоПриобретеннымЦенностям)),
        ,
        СчетКт В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыПоНалогамИСборам)),
        ,
    ) КАК Обороты
```

## Обороты

Обороты по одному счёту с возможностью фильтрации по корреспондирующему счёту.

### Параметры виртуальной таблицы

| Параметр | Описание |
|----------|----------|
| `НачалоПериода` | Начало периода |
| `КонецПериода` | Конец периода |
| `Периодичность` | Периодичность |
| `УсловиеСчета` | Условие на счёт |
| `Субконто` | Условие на субконто |
| `Условие` | Дополнительное условие |
| `УсловиеКорСчета` | Условие на корреспондирующий счёт |
| `КорСубконто` | Условие на субконто кор. счёта |

### Измерения

`Счет`, `Субконто1`, `Субконто2`, `Субконто3`, `КорСчет`, `КорСубконто1`, `КорСубконто2`, `КорСубконто3`, `Организация`, `Валюта`, `ВалютаКор`, `Подразделение`, `ПодразделениеКор`

### Ресурсы

`СуммаОборот`, `СуммаОборотДт`, `СуммаОборотКт`, `КоличествоОборот`, `КоличествоОборотДт`, `КоличествоОборотКт`, `КоличествоКорОборот`, `КоличествоКорОборотДт`, `КоличествоКорОборотКт`, `СуммаНУОборот`, `СуммаНУОборотДт`, `СуммаНУОборотКт`, `СуммаПРОборот`, `СуммаПРОборотДт`, `СуммаПРОборотКт`, `СуммаВРОборот`, `СуммаВРОборотДт`, `СуммаВРОборотКт` + КорОборот-варианты

> ✅ `КоличествоОборот` **есть** (в отличие от `ОборотыДтКт`).

### Пример

```sql
ВЫБРАТЬ
    Обороты.Счет,
    Обороты.Субконто1 КАК Контрагент,
    Обороты.СуммаОборотДт,
    Обороты.СуммаОборотКт
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Обороты(
        &НачДата,
        &КонДата,
        ,
        Счет В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыСПоставщиками)),
        ,
        ,
        ,
    ) КАК Обороты
```

## Остатки

Остатки на конкретную дату (срез).

### Параметры виртуальной таблицы

| Параметр | Описание |
|----------|----------|
| `Период` | **Одна дата** (не диапазон!) |
| `УсловиеСчета` | Условие на счёт |
| `Субконто` | Условие на субконто |
| `Условие` | Дополнительное условие |

> ⚠️ Только **один параметр даты** `Период` — не `НачалоПериода`/`КонецПериода`.

### Измерения

`Счет`, `Субконто1`, `Субконто2`, `Субконто3`, `Организация`, `Валюта`, `Подразделение`

### Ресурсы

`СуммаОстаток`, `СуммаОстатокДт`, `СуммаОстатокКт`, `СуммаРазвернутыйОстатокДт`, `СуммаРазвернутыйОстатокКт`, `ВалютнаяСуммаОстаток`, `ВалютнаяСуммаОстатокДт`, `ВалютнаяСуммаОстатокКт`, `КоличествоОстаток`, `КоличествоОстатокДт`, `КоличествоОстатокКт`, `СуммаНУОстаток`, `СуммаНУОстатокДт`, `СуммаНУОстатокКт`, `СуммаПРОстаток`, `СуммаПРОстатокДт`, `СуммаПРОстатокКт`, `СуммаВРОстаток`, `СуммаВРОстатокДт`, `СуммаВРОстатокКт` + Развернутый-варианты для каждого

### Пример

```sql
ВЫБРАТЬ
    Остатки.Счет,
    Остатки.Субконто1 КАК Контрагент,
    Остатки.СуммаОстатокДт,
    Остатки.СуммаОстатокКт
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Остатки(
        &ДатаОстатков,
        Счет В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыСПокупателями)),
        ,
        Организация = &Организация
    ) КАК Остатки
```

## ОстаткиИОбороты

Начальные/конечные остатки и обороты за период.

### Параметры виртуальной таблицы

| Параметр | Описание |
|----------|----------|
| `НачалоПериода` | Начало периода |
| `КонецПериода` | Конец периода |
| `Периодичность` | Периодичность |
| `МетодДополнения` | Метод дополнения (ДвиженияИГраницыПериода и др.) |
| `УсловиеСчета` | Условие на счёт |
| `Субконто` | Условие на субконто |
| `Условие` | Дополнительное условие |

> ⚠️ **Нет** `УсловиеКорСчета` и `КорСубконто` (в отличие от `Обороты`).

### Измерения

`Счет`, `Субконто1`, `Субконто2`, `Субконто3`, `Организация`, `Валюта`, `Подразделение` (**нет** `КорСчет`)

### Ресурсы (префиксы × типы)

**Префиксы:** `НачальныйОстаток`, `НачальныйРазвернутыйОстаток`, `КонечныйОстаток`, `КонечныйРазвернутыйОстаток`, `Оборот`, `ОборотДт`, `ОборотКт`

**Типы:** `Сумма`, `ВалютнаяСумма`, `Количество`, `СуммаНУ`, `СуммаПР`, `СуммаВР`

Пример: `НачальныйОстатокСумма`, `КонечныйОстатокДт`, `ОборотДтСумма`, `НачальныйРазвернутыйОстатокДтСумма`

### Пример

```sql
ВЫБРАТЬ
    ОстОб.Счет,
    ОстОб.Субконто1,
    ОстОб.НачальныйОстатокДт КАК НачОстДт,
    ОстОб.НачальныйОстатокКт КАК НачОстКт,
    ОстОб.ОборотДт,
    ОстОб.ОборотКт,
    ОстОб.КонечныйОстатокДт КАК КонОстДт,
    ОстОб.КонечныйОстатокКт КАК КонОстКт
ИЗ
    РегистрБухгалтерии.Хозрасчетный.ОстаткиИОбороты(
        &НачДата,
        &КонДата,
        ,
        ,
        Счет В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ОсновныеСредства)),
        ,
        Организация = &Организация
    ) КАК ОстОб
```

## Типичные паттерны использования

### Оборотно-сальдовая ведомость по счёту
→ `ОстаткиИОбороты`

### Анализ корреспонденции 90.03 ↔ 68.02
→ `ОборотыДтКт` с `УсловиеСчетаДт` и `УсловиеСчетаКт`

### Дебиторская/кредиторская задолженность на дату
→ `Остатки` с `Период = &КонДата`

### Обороты по счёту с разбивкой по контрагентам
→ `Обороты` (есть `КоличествоОборот`, `КорСчет`)

### Движения регистра (полная детализация)
→ Реальная таблица `РегистрБухгалтерии.Хозрасчетный` (не виртуальная)
