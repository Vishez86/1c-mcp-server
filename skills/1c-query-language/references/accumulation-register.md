## Основная таблица движений

`РегистрНакопления.<Имя>` — все проводки.

### Стандартные поля

| Поле | Тип | Описание |
|------|-----|----------|
| `<ИмяИзмерения>` | — | Значение измерения |
| `<ИмяРесурса>` | — | Значение ресурса |
| `<ИмяРеквизита>` | — | Дополнительная информация о движении |
| `Период` | Дата | Дата записи |
| `Регистратор` | ДокументСсылка | Документ-источник движения |
| `НомерСтроки` | Число | Номер строки в наборе записей документа |
| `Активность` | Булево | Влияет ли на итоги |
| `ВидДвижения` | ВидДвиженияНакопления | `Приход` или `Расход` — только для регистров **остатков** |

> `ВидДвижения` есть только у регистров остатков; у оборотных регистров его нет.

## Остатки

```
РегистрНакопления.<Имя>.Остатки(<Период>, <Условие>)
```

Только для регистров **остатков**.

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `Период` | Дата, МоментВремени, Граница | На какой момент считать остатки |
| `Условие` | Условие | Фильтр по исходным записям |

### Поля

- Измерения: те же, что в основной таблице
- Ресурсы: `<ИмяРесурса>Остаток` (суффикс **Остаток**)

> Поле `<Ресурс>Остаток` — суммарный остаток (Приход − Расход).
> Если в списке `ВЫБРАТЬ` не указано ни одного измерения, при нулевом остатке вернётся одна строка с нулём (а не пустая выборка). Всегда указывай хотя бы одно измерение.

### Тип параметра Период

| Тип | Поведение |
|-----|-----------|
| `Дата` | Остатки на начало секунды (00:00:00) — движения этого дня **не включаются** |
| `МоментВремени` | Остатки на момент времени, **исключая** движения указанного документа |
| `Граница` с `ВидГраницы.Включая` | Остатки **включая** движения указанного документа |

## Обороты

```
РегистрНакопления.<Имя>.Обороты(<НачалоПериода>, <КонецПериода>, <Периодичность>, <Условие>)
```

Для регистров **остатков** и **оборотных**.

### Параметры

| # | Параметр | Тип | Описание |
|---|----------|-----|----------|
| 1 | `НачалоПериода` | Дата, МоментВремени, Граница | Начало периода (включительно) |
| 2 | `КонецПериода` | Дата, МоментВремени, Граница | Конец периода (включительно). Используй `КОНЕЦПЕРИОДА(&Дата, ДЕНЬ)` для конца дня |
| 3 | `Периодичность` | Ключевое слово | Разворот по периодам (см. ниже) |
| 4 | `Условие` | Условие | Фильтр по исходным записям |

### Поля

- Измерения: те же, что в основной таблице
- `<Ресурс>Оборот` — оборот (Приход − Расход для остатков; сумма всех движений для оборотных)
- `<Ресурс>Приход` — только для регистров **остатков**
- `<Ресурс>Расход` — только для регистров **остатков**
- `Период` — появляется только при указании `Периодичность` ≠ Период
- `Регистратор` — появляется при `Периодичность`: Регистратор или Запись

> `Период` и `Регистратор` из виртуальной таблицы **нельзя использовать в условии ГДЕ**.

### Тип параметра НачалоПериода/КонецПериода

| Тип | Поведение |
|-----|-----------|
| `Дата` | Период с начала секунды НачалоПериода по конец секунды КонецПериода |
| `МоментВремени` | **Включает** движения указанного документа |
| `Граница` с `ВидГраницы.Исключая` | **Исключает** движения указанного документа |

## ОстаткиИОбороты

```
РегистрНакопления.<Имя>.ОстаткиИОбороты(<НачалоПериода>, <КонецПериода>, <Периодичность>, <МетодДополнения>, <Условие>)
```

Только для регистров **остатков**. Наиболее ресурсоёмкая таблица.

### Параметры

| # | Параметр | Описание |
|---|----------|----------|
| 1 | `НачалоПериода` | Начало периода |
| 2 | `КонецПериода` | Конец периода |
| 3 | `Периодичность` | Разворот по периодам |
| 4 | `МетодДополнения` | `Движения` — только периоды с движениями; `ДвиженияИГраницыПериода` — включает граничные периоды (по умолчанию) |
| 5 | `Условие` | Фильтр по исходным записям |

### Поля

- Измерения: те же, что в основной таблице
- `<Ресурс>НачальныйОстаток`
- `<Ресурс>КонечныйОстаток`
- `<Ресурс>Оборот`
- `<Ресурс>Приход`
- `<Ресурс>Расход`
- `Период` — при указании Периодичности
- `Регистратор` — при Периодичности Регистратор/Запись

> Если нужны только остатки — используй `Остатки()`.
> Если нужны только обороты — используй `Обороты()`.
> `ОстаткиИОбороты()` — только когда нужно и то и другое.

### Расчёт итогов по полям остатка

При наличии группировки `Период` в `ИТОГИ ПО` итоги по полям остатков рассчитываются **специальным алгоритмом** (не простым суммированием):
- начальный остаток = из первой записи по каждой комбинации измерений
- конечный остаток = из последней записи

> Итоги по `Регистратор` можно получать **только внутри** группировки `Период`.

## Периодичность — значения параметра

| Значение | Описание |
|----------|----------|
| `Период` | Без разворота, весь интервал (по умолчанию) |
| `Запись` | По каждой записи движения |
| `Регистратор` | По каждому документу-регистратору |
| `Секунда`, `Минута`, `Час` | По секундам, минутам, часам |
| `День`, `Неделя`, `Декада` | По дням, неделям, декадам |
| `Месяц`, `Квартал`, `Полугодие`, `Год` | По месяцам, кварталам и т.д. |
| `Авто` | Автоматически |

## Сравнительная таблица виртуальных таблиц

| | Остатки | Обороты | ОстаткиИОбороты |
|---|---|---|---|
| Тип регистра | Только остатки | Остатки + оборотные | Только остатки |
| Параметр даты | `Период` (одна дата) | `НачДата` + `КонДата` | `НачДата` + `КонДата` |
| МетодДополнения | ❌ | ❌ | ✅ |
| Поля Приход/Расход | ❌ | Только у остатков | ✅ |
| НачальныйОстаток | ❌ | ❌ | ✅ |
| КонечныйОстаток | ❌ | ❌ | ✅ |
| Ресурсоёмкость | Низкая | Средняя | Высокая |

## Примеры

### Остатки товаров на дату

```sql
ВЫБРАТЬ
    ТоварыНаСкладахОстатки.Номенклатура КАК Номенклатура,
    ТоварыНаСкладахОстатки.Склад КАК Склад,
    ТоварыНаСкладахОстатки.КоличествоОстаток КАК Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(
        &Период,
        Номенклатура = &Товар
    ) КАК ТоварыНаСкладахОстатки
```

### Обороты по складам за период

```sql
ВЫБРАТЬ
    Обороты.Номенклатура,
    Обороты.Склад,
    Обороты.КоличествоОборот,
    Обороты.КоличествоПриход,
    Обороты.КоличествоРасход
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Обороты(
        &НачалоПериода,
        КОНЕЦПЕРИОДА(&КонецПериода, ДЕНЬ),
        ,
        Номенклатура = &Товар
    ) КАК Обороты
УПОРЯДОЧИТЬ ПО
    Обороты.Номенклатура
АВТОУПОРЯДОЧИВАНИЕ
```

### Обороты с разворотом по месяцам

```sql
ВЫБРАТЬ
    Обороты.Период,
    Обороты.Номенклатура,
    Обороты.КоличествоОборот КАК Количество,
    Обороты.СуммаОборот КАК Сумма
ИЗ
    РегистрНакопления.Продажи.Обороты(
        &НачалоПериода,
        КОНЕЦПЕРИОДА(&КонецПериода, ДЕНЬ),
        МЕСЯЦ,
        Номенклатура = &Товар
    ) КАК Обороты
УПОРЯДОЧИТЬ ПО
    Период
```

### ОстаткиИОбороты с разворотом по дням

```sql
ВЫБРАТЬ
    ОстОб.Период,
    ОстОб.Номенклатура,
    ОстОб.Склад,
    ОстОб.КоличествоНачальныйОстаток,
    ОстОб.КоличествоПриход,
    ОстОб.КоличествоРасход,
    ОстОб.КоличествоОборот,
    ОстОб.КоличествоКонечныйОстаток
ИЗ
    РегистрНакопления.ТоварыНаСкладах.ОстаткиИОбороты(
        &НачалоПериода,
        КОНЕЦПЕРИОДА(&КонецПериода, ДЕНЬ),
        День,
        Движения,
        Номенклатура = &Товар
    ) КАК ОстОб
```

### Поиск складов без остатков (LEFT JOIN + IS NULL)

```sql
ВЫБРАТЬ
    Склады.Наименование
ИЗ
    Справочник.Склады КАК Склады
    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки(&Период) КАК Остатки
        ПО Остатки.Склад = Склады.Ссылка
ГДЕ
    Остатки.КоличествоОстаток ЕСТЬ NULL
```

### Движения по регистратору

```sql
ВЫБРАТЬ
    Движения.Период,
    Движения.Регистратор,
    Движения.НомерСтроки,
    Движения.ВидДвижения,
    Движения.Номенклатура,
    Движения.Склад,
    Движения.Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах КАК Движения
ГДЕ
    Движения.Регистратор = &Регистратор
УПОРЯДОЧИТЬ ПО
    Движения.НомерСтроки
```
