## Создание и выполнение запроса

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
    "ВЫБРАТЬ
    |    Товары.Наименование КАК Название,
    |    Товары.Цена КАК Цена
    |ИЗ
    |    Справочник.Товары КАК Товары
    |ГДЕ
    |    Товары.Цена > &МинЦена
    |УПОРЯДОЧИТЬ ПО
    |    Товары.Наименование";

Запрос.УстановитьПараметр("МинЦена", 1000);
РезультатЗапроса = Запрос.Выполнить();
```

## Передача параметров

```bsl
// Одиночное значение
Запрос.УстановитьПараметр("Организация", Организация);

// Список значений (для оператора В)
СписокОрг = Новый СписокЗначений;
СписокОрг.Добавить(Ссылка1);
СписокОрг.Добавить(Ссылка2);
Запрос.УстановитьПараметр("СписокОрг", СписокОрг);

// Момент времени (для виртуальных таблиц)
Запрос.УстановитьПараметр("Момент", МоментВремени());

// Граница включая движения документа
ГраницаПоДокумент = Новый Граница(МоментВремени(), ВидГраницы.Включая);
Запрос.УстановитьПараметр("Период", ГраницаПоДокумент);
```

## Обход результата

### Линейный обход (Прямой)

```bsl
ВыборкаЗапроса = РезультатЗапроса.Выбрать();
Пока ВыборкаЗапроса.Следующий() Цикл
    Сообщить(ВыборкаЗапроса.Название + ": " + ВыборкаЗапроса.Цена);
КонецЦикла;
```

### Выгрузка в таблицу значений

```bsl
ТаблицаЗначений = РезультатЗапроса.Выгрузить();
```

## Типы обхода

Применяются когда в запросе есть `ИТОГИ ПО`.

### ПоГруппировкам

```bsl
// Обход групповых итогов, затем детальных записей
ВыборкаГрупп = РезультатЗапроса.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);
Пока ВыборкаГрупп.Следующий() Цикл
    // Текущая запись — групповой итог
    Сообщить("Группа: " + ВыборкаГрупп.Товар + ", итого: " + ВыборкаГрупп.Количество);

    // Детальные записи группы
    ВыборкаДетали = ВыборкаГрупп.Выбрать(); // линейный обход
    Пока ВыборкаДетали.Следующий() Цикл
        Сообщить("  " + ВыборкаДетали.Товар + ": " + ВыборкаДетали.Количество);
    КонецЦикла;
КонецЦикла;
```

### ПоГруппировкамСИерархией

```bsl
// Рекурсивный обход иерархических итогов
Процедура ОбойтиИерархию(ИерархическаяВыборка)
    Пока ИерархическаяВыборка.Следующий() Цикл
        Сообщить(ИерархическаяВыборка.Товар.Наименование +
            " Тип: " + ИерархическаяВыборка.ТипЗаписи() +
            " Уровень: " + ИерархическаяВыборка.Уровень());

        // Получить дочернюю выборку
        Если ИерархическаяВыборка.ТипЗаписи() = ТипЗаписиЗапроса.ИтогПоИерархии Тогда
            Дочерняя = ИерархическаяВыборка.Выбрать(
                ОбходРезультатаЗапроса.ПоГруппировкамСИерархией,
                ИерархическаяВыборка.Группировка());
        Иначе
            Дочерняя = ИерархическаяВыборка.Выбрать(
                ОбходРезультатаЗапроса.ПоГруппировкамСИерархией);
        КонецЕсли;

        ОбойтиИерархию(Дочерняя); // рекурсия
    КонецЦикла;
КонецПроцедуры

// Запуск:
НачальнаяВыборка = РезультатЗапроса.Выбрать(
    ОбходРезультатаЗапроса.ПоГруппировкамСИерархией);
ОбойтиИерархию(НачальнаяВыборка);
```

### Методы выборки

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `ТипЗаписи()` | ТипЗаписиЗапроса | `ОбщийИтог`, `ИтогПоИерархии`, `ИтогПоГруппировке`, `ДетальнаяЗапись` |
| `Уровень()` | Число | Уровень вложенности (0 = верхний) |
| `Группировка()` | Строка | Имя поля группировки; для детальных записей — пустая строка |
| `СледующийПоЗначениюПоля(<Имя>)` | Булево | Следующая запись с другим значением указанного поля |
| `НайтиСледующий(...)` | Булево | Поиск записи по значениям полей |

## Пакетное выполнение

Несколько запросов в одном тексте, разделённых `;`.

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
    "ВЫБРАТЬ Продажи.Товар, Продажи.КоличествоОборот
    |ПОМЕСТИТЬ Обороты
    |ИЗ РегистрНакопления.Продажи.Обороты КАК Продажи
    |;
    |ВЫБРАТЬ Обороты.Товар, Обороты.КоличествоОборот
    |ИЗ Обороты КАК Обороты";

// Выполнить() — вернёт результат последнего результативного запроса
Результат = Запрос.Выполнить();
```

| Метод | Что возвращает |
|-------|----------------|
| `Выполнить()` | Результат последнего результативного запроса пакета |
| `ВыполнитьПакет()` | Массив результатов по каждому запросу (для ВТ — количество записей) |
| `ВыполнитьПакетСПромежуточнымиДанными()` | То же, но для ВТ — её **содержимое** (для отладки) |

```bsl
РезультатПакета = Запрос.ВыполнитьПакет();
ПерваяТаблица = РезультатПакета[0].Выгрузить();
Итог = РезультатПакета[РезультатПакета.ВГраница()].Выгрузить();
```

> Результат запроса на уничтожение ВТ — `Неопределено` (тоже помещается в массив).

## Временные таблицы из BSL (МенеджерВТ)

Позволяет передавать временные таблицы **между несколькими запросами**.

```bsl
// Создать менеджер
МенеджерВТ = Новый МенеджерВременныхТаблиц;

// Привязать запрос к менеджеру
Запрос1 = Новый Запрос;
Запрос1.МенеджерВременныхТаблиц = МенеджерВТ;
Запрос1.Текст =
    "ВЫБРАТЬ
    |    Состав.Номенклатура,
    |    СУММА(Состав.Количество) КАК КоличествоВДокументе
    |ПОМЕСТИТЬ НоменклатураДокумента
    |ИЗ
    |    Документ.ЗаказПокупателя.Состав КАК Состав
    |ГДЕ
    |    Состав.Ссылка = &Ссылка
    |СГРУППИРОВАТЬ ПО
    |    Состав.Номенклатура";
Запрос1.УстановитьПараметр("Ссылка", Ссылка);
Запрос1.Выполнить(); // ВТ НоменклатураДокумента создана в МенеджерВТ

// Второй запрос использует ВТ из того же менеджера
Запрос2 = Новый Запрос;
Запрос2.МенеджерВременныхТаблиц = МенеджерВТ;
Запрос2.Текст =
    "ВЫБРАТЬ
    |    НоменклатураДокумента.Номенклатура,
    |    НоменклатураДокумента.КоличествоВДокументе
    |ИЗ
    |    НоменклатураДокумента КАК НоменклатураДокумента";
Результат = Запрос2.Выполнить();
```

> В пакетном запросе (через `;`) менеджер ВТ не нужен — временные таблицы живут в рамках одного запроса автоматически.
> МенеджерВТ нужен только когда временная таблица должна **переходить между несколькими объектами Запрос**.
> При откате транзакции ВТ, созданные в её рамках, удаляются. `МенеджерВТ.Закрыть()` принудительно удаляет все его таблицы.

## Таблица значений как источник ВТ

```bsl
// Создать таблицу значений
ТЗ = Новый ТаблицаЗначений;
ТЗ.Колонки.Добавить("Номенклатура", Новый ОписаниеТипов("СправочникСсылка.Номенклатура"));
ТЗ.Колонки.Добавить("Количество", Новый ОписаниеТипов("Число", , Новый КвалификаторыЧисла(10, 3)));

// Заполнить...

// Передать как параметр запроса
МенеджерВТ = Новый МенеджерВременныхТаблиц;
Запрос = Новый Запрос;
Запрос.МенеджерВременныхТаблиц = МенеджерВТ;
Запрос.УстановитьПараметр("ТЗ", ТЗ);
Запрос.Текст =
    "ВЫБРАТЬ
    |    ТЗ.Номенклатура,
    |    ТЗ.Количество
    |ПОМЕСТИТЬ ВТИзТЗ
    |ИЗ
    |    &ТЗ КАК ТЗ
    |;
    |ВЫБРАТЬ ...
    |ИЗ ВТИзТЗ КАК ВТИзТЗ ...";
Запрос.Выполнить();
```

> У колонок таблицы значений, используемой как источник ВТ, **обязательно** должны быть явно указаны типы. При создании ВТ из внешнего источника нельзя использовать соединения, объединения и обращения к реквизитам через точку.
