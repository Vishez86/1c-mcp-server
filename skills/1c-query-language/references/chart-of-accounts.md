## ПланСчетов — поля таблицы

`ПланСчетов.<Имя>` — основная таблица.
`ПланСчетов.<Имя>.ВидыСубконто` — специализированная табличная часть.

### Стандартные поля

| Поле | Тип | Описание |
|------|-----|----------|
| `Код` | Строка | Код счёта (например, «60.01») |
| `Наименование` | Строка | Наименование счёта |
| `Порядок` | Строка | Поле для сортировки (используется при `УПОРЯДОЧИТЬ ПО Код` если установлен Автопорядок по коду) |
| `Вид` | ВидСчета | `Активный`, `Пассивный`, `АктивноПассивный` |
| `Забалансовый` | Булево | Признак забалансового счёта |
| `Предопределённый` | Булево | Определён в метаданных |
| `ПометкаНаУдаление` | Булево | — |
| `Родитель` | ПланСчетовСсылка | Ссылка на родительский счёт |
| `Ссылка` | ПланСчетовСсылка | Уникальный идентификатор счёта |
| `Представление` | Строка | Виртуальное поле; текстовое представление |
| `<ИмяПризнакаУчёта>` | Булево | Признак учёта (например, `Количественный`, `Валютный`) — конфигурационное |
| `<ИмяРеквизита>` | — | Реквизиты счёта — конфигурационное |
| `ВидыСубконто` | РезультатЗапроса | Вложенная табличная часть с видами субконто |

### Поля табличной части ВидыСубконто

| Поле | Тип | Описание |
|------|-----|----------|
| `ВидСубконто` | ПланВидовХарактеристикСсылка | Ссылка на вид субконто |
| `Предопределённое` | Булево | Введён в конфигураторе |
| `ТолькоОбороты` | Булево | Только обороты, без остатков |
| `<ИмяПризнакаУчётаСубконто>` | Булево | Например, `Количественный`, `Суммовой` |

## ПланСчетов — правила работы

> ⚠️ **Никогда не фильтруй по коду счёта** — код может измениться пользователем.

```sql
-- НЕВЕРНО
ГДЕ Счёт.Код = "60.01"

-- ВЕРНО — по ссылке (предопределённый счёт)
ГДЕ Счёт.Ссылка = ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыСПоставщиками)

-- ВЕРНО — по параметру
ГДЕ Счёт.Ссылка = &СчётПараметр

-- ВЕРНО — иерархия счётов
ГДЕ Счёт.Ссылка В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыСПоставщиками))
```

> Иерархичность счетов определяется по полю `Родитель`, **не по коду**.

> При `УПОРЯДОЧИТЬ ПО Код` — если у плана счетов установлен «Автопорядок по коду» — фактически сортировка идёт по полю `Порядок`, а не по строке кода. Это правильное поведение.

## Основная таблица движений РегистраБухгалтерии

`РегистрБухгалтерии.<Имя>` — все проводки (без аналитики субконто).

### Стандартные поля

| Поле | Тип | Описание |
|------|-----|----------|
| `СчётДт` | ПланСчетовСсылка | Дебетуемый счёт |
| `СчётКт` | ПланСчетовСсылка | Кредитуемый счёт |
| `<Ресурс>Дт` | — | Значение небалансового ресурса по дебету |
| `<Ресурс>Кт` | — | Значение небалансового ресурса по кредиту |
| `<БалансовыйРесурс>` | — | Значение балансового ресурса (например, `Сумма`) |
| `<ИмяИзмерения>Дт` | — | Небалансовое измерение по дебету |
| `<ИмяИзмерения>Кт` | — | Небалансовое измерение по кредиту |
| `<БалансовоеИзмерение>` | — | Балансовое измерение (например, `Организация`) |
| `<ИмяРеквизита>` | — | Реквизит проводки (например, `Содержание`) |
| `Период` | Дата | Дата проводки |
| `Регистратор` | ДокументСсылка | Документ-источник |
| `НомерСтроки` | Число | Номер строки в наборе документа |
| `Активность` | Булево | Влияет на итоги |

> Основная таблица содержит **проводки без данных субконто**. Для получения субконто используется виртуальная таблица `ДвиженияССубконто`.

### Виртуальная таблица ДвиженияССубконто

```
РегистрБухгалтерии.<Имя>.ДвиженияССубконто(<НачДата>, <КонДата>, <Условие>, ...)
```

Объединяет основную таблицу с таблицей значений субконто. Содержит дополнительные поля:
- `СубконтоДт<N>` — значение N-го субконто по дебету
- `СубконтоКт<N>` — значение N-го субконто по кредиту

## Примеры запросов к ПланСчетов

### Список всех счетов

```sql
ВЫБРАТЬ
    ПланСчетов.Код,
    ПланСчетов.Наименование,
    ПланСчетов.Вид,
    ПланСчетов.Забалансовый,
    ПланСчетов.Количественный
ИЗ
    ПланСчетов.Хозрасчетный КАК ПланСчетов
УПОРЯДОЧИТЬ ПО
    Код
```

### Только активно-пассивные счета

```sql
ВЫБРАТЬ
    ПланСчетов.Код,
    ПланСчетов.Наименование
ИЗ
    ПланСчетов.Хозрасчетный КАК ПланСчетов
ГДЕ
    ПланСчетов.Вид = ЗНАЧЕНИЕ(ВидСчета.АктивноПассивный)
УПОРЯДОЧИТЬ ПО
    Код
```

### Счета с количественным учётом

```sql
ВЫБРАТЬ
    ПланСчетов.Код,
    ПланСчетов.Наименование
ИЗ
    ПланСчетов.Хозрасчетный КАК ПланСчетов
ГДЕ
    ПланСчетов.Количественный = ИСТИНА
УПОРЯДОЧИТЬ ПО
    Код
```

### Счета в иерархии заданного счёта

```sql
ВЫБРАТЬ
    ПланСчетов.Код,
    ПланСчетов.Наименование
ИЗ
    ПланСчетов.Хозрасчетный КАК ПланСчетов
ГДЕ
    ПланСчетов.Ссылка В ИЕРАРХИИ (&Счёт)
УПОРЯДОЧИТЬ ПО
    Код
```

### Виды субконто счёта (через ВидыСубконто как отдельная таблица)

```sql
ВЫБРАТЬ *
ИЗ
    ПланСчетов.Хозрасчетный.ВидыСубконто КАК ВидыСубконто
ГДЕ
    ВидыСубконто.Ссылка = &Счёт
```

## Примеры запросов к движениям

### Движения по описанию проводки

```sql
ВЫБРАТЬ
    Движения.Период,
    Движения.Регистратор,
    Движения.НомерСтроки,
    Движения.СчётДт,
    Движения.КоличествоДт,
    Движения.СчётКт,
    Движения.КоличествоКт,
    Движения.Сумма
ИЗ
    РегистрБухгалтерии.Хозрасчетный КАК Движения
ГДЕ
    Движения.Содержание ПОДОБНО "%Покупка%"
УПОРЯДОЧИТЬ ПО
    Движения.Период
```

### Движения по регистратору

```sql
ВЫБРАТЬ
    Движения.Период,
    Движения.НомерСтроки,
    Движения.СчётДт,
    Движения.СчётКт,
    Движения.Сумма
ИЗ
    РегистрБухгалтерии.Хозрасчетный КАК Движения
ГДЕ
    Движения.Регистратор = &Регистратор
```
