### Замечание по рабочей копии (устранено)
Файлы в рабочей копии хранятся в **CRLF/UTF-8**, тогда как блобы HEAD — в **LF** (поэтому `git diff` без
`--ignore-cr-at-eol` показывает «изменён весь репозиторий» — это EOL-шум, не правки). В ходе работы три
редактируемых файла оказались усечены с конца на ~30–45 строк; они **перезаписаны заново из чистого HEAD с
повторным применением правок** (байт-безопасно, CRLF как у соседних файлов). Итоговые длины: `MCP_Query.bsl`
2685, `MCP_Tools_Impl.bsl` 5711, `INSTALL.md` 325 строк — концы файлов корректны.
