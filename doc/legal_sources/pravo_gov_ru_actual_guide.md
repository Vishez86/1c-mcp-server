> Рабочая копия зашита в `src/CommonModules/MCP_LegalSources.bsl` (функция `ИнструкцияPravoGovRuActual`);
> может быть переопределена записью регистра сведений `MCP_ПравовыеИсточники`. Порядок обновления:
> правим здесь (или в Google Docs) → переносим в модуль или регистр.
> Факты проверены вживую 28.07.2026: поиск, карточка, редакции и текст ТК РФ получены по описанным
> вызовам; актуальная редакция ТК РФ на тот момент — с 18.05.2026, присутствовали будущие редакции
> (01.09.2026, 01.03.2027). ВАЖНО: API недокументированный (реверс веб-интерфейса), возможны изменения.

ИСТОЧНИК: Официальный интернет-портал правовой информации — раздел «Тексты правовых актов с внесенными изменениями» (actual.pravo.gov.ru).

ЧТО ЭТО И ЗАЧЕМ.
Это раздел того же государственного портала pravo.gov.ru, где размещаются КОНСОЛИДИРОВАННЫЕ тексты — акт целиком со всеми
внесенными изменениями. Ведется по Указу Президента РФ от 03.03.2022 № 90. Именно сюда иди за «действующей редакцией»
Трудового, Налогового и любого другого кодекса, Конституции, федеральных законов, указов и постановлений Правительства.
Тексты федеральных актов в банке «Законодательство России» имеют официальный статус. Для каждого акта хранится история
редакций, включая будущие (еще не вступившие в силу) — можно ответить и «как сейчас», и «как будет с 1 сентября».

ДОСТУП И АУТЕНТИФИКАЦИЯ.
Аутентификации нет. Веб-интерфейс: http://actual.pravo.gov.ru (работай по http). REST API, на котором работает сам сайт:
http://actual.pravo.gov.ru:8000/api/ebpi/ — открыт, отвечает JSON, но ОФИЦИАЛЬНО НЕ ДОКУМЕНТИРОВАН (описан по устройству
веб-интерфейса, проверен вживую 28.07.2026). Он может измениться без предупреждения: если запросы перестали работать —
не выдумывай, сверься с веб-интерфейсом и скажи пользователю о сбое.

БЫСТРЫЙ ПУТЬ ДЛЯ КОДЕКСОВ.
Кодексы не надо искать: страница http://pravo.gov.ru/codex/ содержит готовые ссылки на все кодексы РФ вида
http://actual.pravo.gov.ru/content/content.html#hash={dochash}&ttl=1 — из ссылки бери dochash. Конституция: /constitution/.

ПОИСК ПРОЧИХ АКТОВ: GET /api/ebpi/attrsearch/?bpa=ebpi&q={JSON}.
q — URL-кодированный JSON-массив условий. Поиск по наименованию: условие {"AttrId":7,"AttrMode":9,"Words":[...]},
где Words — слова наименования, КАЖДОЕ с префиксом «+», например ["+трудовой","+кодекс"]. Последним элементом массива
всегда добавляй служебный блок {"AttrId":999,"AttrMode":1,"Words":[50,"position","20220701",0,0]}
(50 — лимит выдачи; ПОСЛЕДНИЙ НОЛЬ ОБЯЗАТЕЛЕН — с единицей кодексы и часть видов актов выпадают из выдачи).
Пример (до URL-кодирования): q=[{"AttrId":7,"AttrMode":9,"Words":["+трудовой","+кодекс"]},{"AttrId":999,"AttrMode":1,"Words":[50,"position","20220701",0,0]}]
В ответе docs[]: docid, dochash (главный идентификатор, сохраняй), docpassing (вид, дата, номер), docnames, docstate.

КАРТОЧКА И РЕДАКЦИИ.
Карточка: GET /api/ebpi/card/?bpa=ebpi&t={"hash":"{dochash}"} — реквизиты, состояние, публикации.
Редакции: GET /api/ebpi/redactions/?bpa=ebpi&t={"hash":"{dochash}","ttl":1} — массив redactions[], у каждой:
redid (номер редакции), redcaption («с 18.05.2026, актуальная»), redstatus, actual (true = действующая сейчас),
redofficial (официальный текст), reddate (в т.ч. будущие даты — не вступившие в силу редакции).
Выбирай редакцию с actual=true; для вопроса «как будет с даты X» — редакцию с reddate=X.

ТЕКСТ РЕДАКЦИИ — АДРЕСНО, НЕ ЦЕЛИКОМ.
Полный текст: GET /api/ebpi/redtext?bpa=ebpi&t={redid}&ttl=0 — JSON с полем redtext (HTML). ВНИМАНИЕ: кодексы весят
больше мегабайта — не тащи весь текст в контекст. Сначала оглавление: GET /api/ebpi/getcontent/?bpa=ebpi&rdk={redid} —
структура до статьи и части статьи (caption «Статья 157. ...»). Затем из redtext вырежи только нужную статью — ищи по
заголовку статьи. Цитируй норму дословно и указывай редакцию («в редакции на 18.05.2026»).

ССЫЛКА ДЛЯ ПОЛЬЗОВАТЕЛЯ.
http://actual.pravo.gov.ru/content/content.html#hash={dochash}&ttl=1 — открывается актуальный текст акта.

ОГРАНИЧЕНИЯ И ПОДВОДНЫЕ КАМНИ.
1. Корпус: кодексы, Конституция и основные федеральные акты, плюс акты, изменявшиеся после 01.07.2022. Старый акт без
   недавних изменений может отсутствовать — тогда ищи его в источнике pravo_gov_ru (лента опубликования) и честно скажи,
   что это первоначальная редакция.
2. Ведомственных приказов (с регистрацией в Минюсте) здесь в основном нет — они в pravo_gov_ru.
3. API недокументирован: формат может измениться. Не подбирай параметры наугад — используй только описанные здесь вызовы.
4. Порт 8000 может быть закрыт из некоторых сетей; тогда работай через веб-ссылку для пользователя.

РАЗДЕЛЕНИЕ РОЛЕЙ: СНАЧАЛА РЕШИ, ПОТОМ ИЩИ.
Реши сам, какой акт и какая статья нужны, ДО обращения к API. Один точечный поиск по наименованию, один запрос редакций,
одна статья из текста. Сканировать банк, выкачивать кодексы целиком или перебирать выдачу без гипотезы нельзя.

ПОЛИТИКА.
Законодательство ищем только через источники из list_legal_sources. Открытый интернет (поисковики, КонсультантПлюс, Гарант,
сторонние пересказы) не используем. Если нормы здесь нет — скажи об этом пользователю и предложи уточнить реквизиты,
а не подменяй ответ догадками.
