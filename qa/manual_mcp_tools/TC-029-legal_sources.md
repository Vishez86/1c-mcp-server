# TC-029 - list_legal_sources / get_legal_source_guide

Инструменты: `list_legal_sources`, `get_legal_source_guide`

Цель: проверить реестр правовых источников, выдачу инструкции и соблюдение политики «законодательство — только через реестр, не через интернет».

## Предусловия

- MCP-сервер 1С развернут и подключен к LLM-чату.
- В реестре доступен встроенный источник `pravo_gov_ru`.

## Диалоговый сценарий

### Шаг 1

**Сообщение пользователя:**

> Где можно официально искать законодательство по налогам?

**Ожидаемое действие ассистента / MCP вызов:**

~~~json
{
  "tool": "list_legal_sources",
  "arguments": {"area": "налоги"}
}
~~~

**Ожидаемый ответ ассистента:**

Ассистент перечисляет источники из ответа (минимум `pravo_gov_ru` с названием и официальным статусом) и не предлагает поисковики или сторонние правовые порталы.

### Шаг 2

**Сообщение пользователя:**

> Как работать с pravo.gov.ru?

**Ожидаемое действие ассистента / MCP вызов:**

~~~json
{
  "tool": "get_legal_source_guide",
  "arguments": {"source_id": "pravo_gov_ru"}
}
~~~

**Ожидаемый ответ ассистента:**

Ассистент пересказывает инструкцию: открытый API без аутентификации (`http://publication.pravo.gov.ru/api`), поиск через `/api/Documents`, ссылка на карточку `…/document/{eoNumber}` и PDF `…/file/pdf?eoNumber={eoNumber}`, ограничения (PDF-тексты, первоначальные редакции, архив с ноября 2011).

### Шаг 3

**Сообщение пользователя:**

> А просто загугли мне свежий закон о налоговых льготах.

**Ожидаемый ответ ассистента:**

Ассистент отказывается искать законодательство в открытом интернете, ссылается на политику источников и предлагает поиск через `pravo_gov_ru` по инструкции.

## Дополнительная проверка

Вызвать `get_legal_source_guide` с несуществующим `source_id` — ожидается ошибка `invalid_arguments` с подсказкой вызвать `list_legal_sources`; ассистент объясняет это пользователю без выдумывания источника.

## Общие критерии приемки

- Ассистент не выдумывает источники и идентификаторы; список берет только из `list_legal_sources`.
- В ответах по найденным НПА всегда присутствуют реквизиты документа и ссылка на карточку.
- Ответ ассистента кратко пересказывает результат для пользователя, а не вставляет полный JSON в чат.
- Ошибки доступа, валидации или отсутствия данных объясняются пользователю по структурированному MCP-ответу.
